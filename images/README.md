# Фото для сайту

Збережіть фото з Instagram @forsage.cafe.uzh (без облич) у цю папку з такими іменами.
Якщо файлу немає, на його місці показується стриманий темний фон, тож сайт виглядає цілісно навіть без фото.

| Файл | Що поставити |
|---|---|
| `hero.jpg` | Головне фото: зала ввечері / тераса з лампами (горизонтальне, велике) |
| `interior.jpg` | Інтер'єр кафе |
| `terrace.jpg` | Літня тераса |
| `drink.jpg` | Фірмовий напій «Forsage» |
| `dish-1.jpg` … `dish-5.jpg` | Страви: бограч, стейк, банош, салат, гриль-сет |
| `room.jpg` | Номер у готелі |
| `hostel.jpg` | Хостел |
| `sauna.jpg` | Баня |
| `gallery-1.jpg` … `gallery-7.jpg` | Атмосферні фото для галереї |

Порада: стискайте фото до ~1600px по ширині (наприклад, на squoosh.app), щоб сайт швидко завантажувався.
