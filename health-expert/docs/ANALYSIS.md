## 2. Важные ограничения MVP

- **Обезличивание на регулярных выражениях.** Оно ловит ИИН, телефоны, e-mail, адреса, номера документов,
  коды МКБ, типовые ФИО и диагнозы после слова «диагноз». Нестандартные написания имён могут пройти.
  Для эксплуатации рекомендуется добавить NER-модель для ru/kk, работающую локально, и выборочный аудит.
- **Офлайн-режим — не замена модели.** Он нужен для демонстрации, тестов и работы при недоступности модели.
  На демо-наборе он находит верную норму менее чем в половине вопросов (3 из 7). Качество промышленного режима
  измеряется регрессионным тестом с подключённой моделью на контрольном наборе заказчика.
- **SQLite.** Подходит для ~1000 документов и небольшой группы операторов. Для роста — PostgreSQL
  (tsvector + pgvector). Логика при этом не меняется: SQL сосредоточен в `db.py`, `ingest.py`, `search.py`.
- **Исправленный ответ** сотрудника хранится локально вместе с восстановленными ПДн. Обезличенный текст
  хранится отдельно, исходный текст обращения не хранится.

## 3. Решения для этапа анализа

**Модель.** Подключён Claude (`claude-opus-5-5`) через Anthropic API: структурированный JSON-вывод и
серверный fallback при отказе. Если данные нельзя передавать за пределы РК даже обезличенными, модель
заменяется на локальную через тот же интерфейс `LLM` (`expert/llm/base.py`).

**RAG-платформа.** Сейчас RAG собственный и лёгкий: данные и индекс полностью под контролем заказчика. Варианты сравнения:

| Вариант | Плюсы | Минусы |
|---|---|---|
| Собственный (текущий) + PostgreSQL/pgvector | всё локально, «на дату» и редакции — нативно в SQL | поддержка своими силами |
| Qdrant / OpenSearch (self-hosted) | масштаб, гибридный поиск из коробки | фильтрацию по редакциям и датам нужно повторить в метаданных |
| Облачные RAG-сервисы | быстро запустить | индекс вне контура заказчика — противоречит п. 5 ТЗ |

**Эмбеддер.** Многоязычная модель с поддержкой казахского, развёрнутая локально (например, BGE-M3 или
multilingual-e5-large). Подключается реализацией `Embedder` в `vectors.py`, затем векторы пересчитываются.

## 4. Открытые вопросы к заказчику (из п. 10 ТЗ)

1. Перечень источников и ~1000 НПА (коды adilet) → `sources.toml`.
2. Контрольный набор вопросов с эталонными нормами → `gold_set` (формат — `data/demo/gold.json`).
3. Пороги уверенности, доля выборочной проверки, порог приёмки.
4. Вариант ответа по умолчанию. Сейчас — «со ссылками», оператор переключает для каждого вопроса.
5. Где размещать: собственный сервер или облако в РК. Допустима ли внешняя модель для обезличенных данных.
6. Целевое время ответа и бюджет на запросы к модели.
