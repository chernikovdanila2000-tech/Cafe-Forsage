# Сайт школы английского языка

Лендинг школы, личный кабинет с уроками, оплата уроков по ссылке, база данных аккаунтов и админ-панель.

## Запуск

Нужен **Node.js 22.13 или новее** (база SQLite встроена в Node, отдельно ставить ничего не нужно).

```bash
cd english-school
npm install
npm start
```

Сайт откроется на http://localhost:3000. При первом запуске в консоли появится логин и пароль администратора — сохраните их.

## Что есть на сайте

| Страница | Что там |
|---|---|
| `/` | Главная: подход, программа, цены, преподаватели, вопросы, форма заявки на консультацию |
| `/register`, `/login` | Регистрация и вход (пароли хранятся в виде хэша scrypt) |
| `/dashboard` | Личный кабинет: прогресс, список уроков, кнопки «Оплатить», история оплат |
| `/lessons/:id` | Урок: теория, словарь, тест с проверкой, отметка «пройден» |
| `/pay/:id` | Ссылка на оплату урока |
| `/account` | Профиль и смена пароля |
| `/admin` | Админ-панель: все аккаунты, платежи (подтверждение / отмена), заявки |

Первый урок бесплатный, остальные открываются после оплаты.

## База данных

Файл `data/school.db` (SQLite) создаётся автоматически. Таблицы:
`users` (аккаунты), `sessions` (входы), `lessons` (уроки), `payments` (оплаты),
`progress` (пройденные уроки), `requests` (заявки с сайта).

Делайте резервную копию, просто копируя файл `data/school.db`.

## Оплата

Пока `PAYMENT_URL` не задан, работает **демо-оплата** — удобно, чтобы проверить сайт.
Для настоящих платежей укажите ссылку на страницу оплаты (ЮKassa, Robokassa, Тинькофф, Stripe Payment Link и т. п.):

```bash
PAYMENT_URL="https://ваш-платёжный-сервис/pay?order={payment}&sum={amount}" npm start
```

Подстановки: `{payment}` — номер платежа, `{lesson}` — номер урока, `{amount}` — сумма, `{email}` — email ученика.
Без подстановок параметры добавятся к ссылке автоматически.

Как работает: ученик нажимает «Оплатить» → на сайте создаётся платёж со статусом «Ожидает» → ученик переходит на страницу оплаты.
После поступления денег администратор нажимает «Подтвердить» в `/admin`, и урок открывается.
В платёжном сервисе в качестве адреса возврата можно указать `https://ваш-сайт/payment/success`.

> Для полной автоматизации (без ручного подтверждения) нужно подключить уведомления (webhook) вашего платёжного сервиса — это отдельная доработка под конкретный сервис.

## Настройки

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `PORT` | `3000` | Порт сервера |
| `SCHOOL_NAME` | `Elmwood` | Название школы |
| `SCHOOL_PHONE`, `SCHOOL_EMAIL` | примеры | Контакты в подвале |
| `CURRENCY` | `₽` | Валюта |
| `TUTOR_PRICE` | `1900` | Цена занятия с преподавателем на главной |
| `PAYMENT_URL` | — | Ссылка на оплату |
| `ADMIN_EMAIL`, `ADMIN_PASSWORD` | `admin@school.local`, случайный | Данные администратора |
| `SECURE_COOKIES` | `false` | Поставьте `true`, когда сайт работает по HTTPS |
| `DB_PATH` | `data/school.db` | Путь к базе |

## Как поменять контент

- **Уроки** — `lessons.js`. Добавьте объект в массив (новый уникальный `id`), перезапустите сервер — урок появится в базе и на сайте.
- **Преподаватели** — `config.js` (сейчас там примеры, замените на реальных).
- **Тексты главной страницы** — `views.js`, функция `home`.
- **Цвета и шрифты** — переменные в начале `public/styles.css`.
