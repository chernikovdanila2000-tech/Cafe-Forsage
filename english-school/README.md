# Inkwell Academy — сайт онлайн-школы английского

Индивидуальные занятия с преподавателем онлайн: заявки на бесплатную консультацию, регистрация, личный кабинет ученика, оплата (разовое занятие или абонемент), админ-панель. Языки: украинский (по умолчанию) и английский.

## Что умеет сайт

**Для посетителя**
- Главная: «для кого», как проходят занятия, цены, преподаватели, отзывы, вопросы, форма «Безкоштовна консультація»
- После заявки — страница «Дякуємо» (на ней срабатывает событие `Lead` для рекламы)
- Регистрация с согласием на оферту, вход, «Забули пароль?»
- Личный кабинет: сколько оплаченных занятий осталось, кнопки оплаты, история оплат
- Оферта `/offer` и политика конфиденциальности `/privacy` подставляют реквизиты и цены автоматически

**Цены** (меняются в админке, всё пересчитывается само)
- Консультация 20 мин — бесплатно
- Разовое занятие 60 мин — 450 ₴
- Абонемент: 8 занятий (2 в неделю) — 3 600 ₴ − 20% = **2 880 ₴** (360 ₴ за занятие, экономия 720 ₴)

**Админ-панель `/admin`**
- **Огляд** — чек-лист «Готовність до запуску», новые заявки, оплаты на проверку
- **Заявки** — с источником (utm-метки рекламы), отметка «Опрацьовано»
- **Учні** — остаток занятий, кнопка «Заняття проведено», сброс пароля
- **Оплати** — «Підтвердити» зачисляет занятия ученику
- **Викладачі** и **Відгуки** — добавляются с фото; пока пусто, раздел на сайте скрыт
- **Налаштування** — контакты, цены, оплата, реквизиты ФОП, Meta Pixel, Google Analytics, Telegram-бот

**Чат ученика с преподавателем**
- Преподаватель регистрируется на сайте как обычный пользователь → в админке «Учні» нажмите «Зробити викладачем»
- Там же в колонке «Викладач» выберите преподавателя для ученика — у обоих появится общий чат
- В чате: текст, фото, PDF, Word/Excel/PowerPoint, аудио и видео до 20 МБ (до 5 файлов за раз); новые сообщения появляются без перезагрузки
- Файлы видят только ученик, его преподаватель и администратор
- У преподавателя свой кабинет `/teacher`: его ученики, непрочитанные сообщения, кнопка «Заняття проведено»
- Администратор видит все чаты в разделе «Чати» и может писать в них

**Уведомления в Telegram**: новая заявка, регистрация, заказ, оплата, сообщение ученика в чате (не чаще раза в 10 минут на ученика).

## Оплата

В админке → «Налаштування» → «Оплата» заполните одно из двух:
- **Посилання на оплату** (WayForPay, LiqPay, monobank) — ученик сразу переходит на оплату. Можно вставить `{amount}`, `{payment}`, `{product}`, `{email}`.
- **Реквізити** (IBAN) — ученик видит реквизиты и номер заказа, а вы после поступления денег жмёте «Підтвердити» в разделе «Оплати».

Если не заполнено ничего — заказ принимается, вы получаете уведомление и связываетесь с учеником сами.

Демо-оплата (кнопка, которая зачисляет занятия без денег) работает **только на своём компьютере**. На Railway она отключена автоматически.

## Запуск на Railway

1. Сервис из GitHub, ветка с сайтом, **Root Directory**: `/english-school`.
2. **Volume с путём `/data` — обязательно!** Без него при каждом перезапуске Railway стираются все аккаунты, оплаты и файлы чатов (правой кнопкой по сервису → Attach Volume). Сайт сам положит туда базу и фото. Без Volume в админке будет красное предупреждение.
3. **Variables**: `ADMIN_EMAIL` и `ADMIN_PASSWORD` — ваш вход в админку. Больше ничего не обязательно: остальное настраивается в `/admin/settings`.
4. **Networking → Generate Domain** или свой домен (Custom Domain).
5. Зайдите в `/admin` и пройдите чек-лист «Готовність до запуску».

Проверка, что сервер жив: `/health` → `{"ok":true,"persistentStorage":true}`.

## Реклама

- Meta Pixel ID и Google Analytics ID вставляются в «Налаштування». Сайт сам отправляет события: `PageView`, `Lead` (заявка), `CompleteRegistration`, `InitiateCheckout`, `Purchase`.
- Ставьте в ссылках рекламы utm-метки, например `https://inkwell.academy/?utm_source=instagram&utm_campaign=start` — источник появится у каждой заявки и ученика в админке.
- Превью ссылки (Instagram, Telegram, Facebook): `public/og.png`.

## Локально

Нужен Node.js 22.13+.

```bash
cd english-school
npm install
npm start      # http://localhost:3000
npm test       # 21 автоматическая проверка сайта
```

Если `ADMIN_PASSWORD` не задан, пароль администратора `admin@school.local` печатается в консоли при первом запуске.

## Переменные окружения (необязательные)

Все поля из «Налаштування» можно задать и переменными — значение из админки важнее:
`SCHOOL_PHONE`, `SCHOOL_EMAIL`, `SCHOOL_TELEGRAM`, `SCHOOL_INSTAGRAM`, `LESSON_PRICE`, `SUBSCRIPTION_LESSONS`, `SUBSCRIPTION_DISCOUNT`, `PAYMENT_URL`, `PAYMENT_DETAILS`, `LEGAL_SELLER`, `LEGAL_TAX_ID`, `LEGAL_ADDRESS`, `SITE_URL`, `META_PIXEL_ID`, `GA_MEASUREMENT_ID`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`.

Прочие: `PORT`, `DB_PATH`, `SCHOOL_NAME`, `SCHOOL_TAGLINE`, `DEMO_PAYMENTS` (`true`/`false`), `LEGAL_UPDATED`.
