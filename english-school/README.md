# Сайт школы английского языка

Лендинг школы, личный кабинет с уроками, оплата уроков по ссылке, база данных аккаунтов и админ-панель.

## Запуск

Нужен **Node.js 22.13 или новее** (база SQLite встроена в Node, отдельно ставить ничего не нужно).

```bash
cd english-school
npm install
npm start
```

Сайт откроется на http://localhost:3000. При первом запуске в консоли появится логин и пароль администратора — сохраните их.

## Публикация на Railway

1. **Код.** Railway берёт код из GitHub. В проекте нажмите *New → GitHub Repo*, выберите этот репозиторий и ветку с сайтом.
2. **Папка.** *Settings → Source → Root Directory*: `/english-school`. Команды указывать не нужно, Railway сам выполнит `npm install` и `npm start`.
3. **Диск для базы (обязательно).** Без него база с аккаунтами будет стираться при каждом обновлении сайта.
   Нажмите на сервис правой кнопкой (или `⌘K`) → *Attach Volume*, путь монтирования — `/data`.
   Сайт сам найдёт подключённый Volume и положит базу туда. Если Volume нет, в админ-панели и в логах будет предупреждение.
4. **Variables** (вкладка *Variables*):

   | Переменная | Значение |
   |---|---|
   | `SECURE_COOKIES` | `true` |
   | `ADMIN_EMAIL` | ваш email для входа в админку |
   | `ADMIN_PASSWORD` | надёжный пароль администратора |
   | `SCHOOL_PHONE`, `SCHOOL_EMAIL` | контакты школы |
   | `PAYMENT_URL` | ссылка на оплату (когда будет готова) |

   `PORT` задавать не нужно, его выдаёт Railway.
5. **Проверка.** *Settings → Networking → Generate Domain* даст временный адрес вида `….up.railway.app`. Убедитесь, что сайт открывается и вход в `/admin` работает.
6. **Свой домен.** *Settings → Networking → Custom Domain* → введите домен. Railway покажет DNS-запись (CNAME и TXT для проверки), добавьте её в панели регистратора домена. Обновление DNS занимает от нескольких минут до суток.
   Для домена без `www` регистратор должен поддерживать CNAME/ALIAS на корне. Если не поддерживает, подключите `www.ваш-домен` или перенесите DNS в Cloudflare (бесплатно).

## Если сайт не открывается

- **Адрес `localhost` работает только на том компьютере, где запущен сервер.** С другого устройства или с сервера хостинга открывайте `http://IP-адрес-сервера:3000` (или ваш домен).
- **Окно терминала с `npm start` должно оставаться открытым** — закрыли окно, сайт остановился. На сервере запускайте через `pm2` (см. ниже).
- **«Нужен Node.js 22.13 или новее»** — обновите Node.js: https://nodejs.org (версия LTS). Проверить версию: `node -v`.
- **«Порт уже занят»** — запустите на другом порту: `PORT=8080 npm start`.
- **На VPS сайт не открывается снаружи** — откройте порт в файрволе (`sudo ufw allow 3000`) и в панели хостинга, либо настройте Nginx на порт 80/443.
- **На хостинге вроде Render / Railway / Timeweb Apps** — команда сборки `npm install`, команда запуска `npm start`, корневая папка `english-school`. Порт сайт берёт из переменной `PORT`, которую выдаёт хостинг. Обычный «виртуальный хостинг» только для PHP/HTML этот сайт не запустит — нужен хостинг с поддержкой Node.js или VPS.

### Постоянная работа на сервере (VPS)

```bash
npm install -g pm2
cd english-school && npm install
pm2 start server.js --name school
pm2 save && pm2 startup
```

## Что есть на сайте

Сайт на двух языках: украинский (по умолчанию) и английский, переключатель UA / EN в шапке.

| Страница | Что там |
|---|---|
| `/` | Главная: подход, формат занятий, цены, преподаватели, вопросы, заявка на бесплатную консультацию |
| `/register`, `/login` | Регистрация и вход (телефон обязателен, чтобы преподаватель мог связаться) |
| `/dashboard` | Личный кабинет: сколько оплаченных занятий осталось, кнопки оплаты, история оплат |
| `/pay/single` | Оплата разового занятия (450 ₴) |
| `/pay/monthly` | Оплата абонемента: 8 занятий в месяц (2 в неделю), 3 600 ₴ − 20% = 2 880 ₴ |
| `/account` | Профиль и смена пароля |
| `/admin` | Админ-панель: оплаты (подтверждение / отмена), ученики с остатком занятий и кнопкой «Заняття проведено», заявки |

Все занятия индивидуальные, с преподавателем, по 60 минут, без привязки к темам. После оплаты занятия зачисляются ученику, а преподаватель связывается с ним по телефону. Когда занятие проведено, администратор отмечает это в `/admin`, и у ученика списывается одно занятие.

## База данных

Файл `data/school.db` (SQLite) создаётся автоматически. Таблицы:
`users` (аккаунты), `sessions` (входы), `orders` (оплаты: разовые занятия и абонементы),
`attendance` (проведённые занятия), `requests` (заявки с сайта).

Делайте резервную копию, просто копируя файл `data/school.db`.

## Оплата

Пока `PAYMENT_URL` не задан, работает **демо-оплата** — удобно, чтобы проверить сайт.
Для настоящих платежей укажите ссылку на страницу оплаты (WayForPay, LiqPay, Plata by mono, Stripe Payment Link и т. п.):

```bash
PAYMENT_URL="https://ваш-платёжный-сервис/pay?order={payment}&sum={amount}" npm start
```

Подстановки: `{payment}` — номер заказа, `{product}` — `single` или `monthly`, `{amount}` — сумма, `{email}` — email ученика.
Без подстановок параметры добавятся к ссылке автоматически.

Как работает: ученик нажимает «Оплатить» → на сайте создаётся заказ со статусом «Ожидает» → ученик переходит на страницу оплаты.
После поступления денег администратор нажимает «Подтвердить» в `/admin`, и занятия зачисляются ученику.
В платёжном сервисе в качестве адреса возврата можно указать `https://ваш-сайт/payment/success`.

> Для полной автоматизации (без ручного подтверждения) нужно подключить уведомления (webhook) вашего платёжного сервиса — это отдельная доработка под конкретный сервис.

## Настройки

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `PORT` | `3000` | Порт сервера |
| `SCHOOL_NAME` | `Inkwell Academy` | Название школы |
| `SCHOOL_TAGLINE` | `School of English` | Подпись под логотипом |
| `SCHOOL_PHONE`, `SCHOOL_EMAIL` | примеры | Контакты в подвале |
| `CURRENCY` | `₴` | Валюта |

## Оферта и политика конфиденциальности

Страницы `/offer` (публичный договор-оферта) и `/privacy` (политика конфиденциальности) на украинском, ссылки на них — в подвале, при регистрации и рядом с оплатой. При регистрации нужно поставить галочку согласия.

Это шаблон. Перед подключением оплаты заполните реквизиты в Railway → *Variables*:

| Переменная | Пример |
|---|---|
| `LEGAL_SELLER` | `ФОП Петренко Олена Іванівна` |
| `LEGAL_TAX_ID` | РНОКПП (ИНН) ФОП |
| `LEGAL_ADDRESS` | адрес регистрации |
| `SITE_URL` | `https://inkwell.academy` |
| `LEGAL_UPDATED` | дата редакции, например `26.10.2026` |

Пока реквизиты не заданы, на их месте показываются жёлтые пометки «вкажіть…». Условия переноса, возврата и срока абонемента — в `legal.js`; перед запуском желательно показать текст юристу.

## Как поменять контент

- **Цены** — переменные `LESSON_PRICE`, `SUBSCRIPTION_LESSONS`, `SUBSCRIPTION_DISCOUNT`; цена абонемента считается автоматически.
- **Преподаватели** — `config.js` (сейчас там примеры, замените на реальных).
- **Тексты сайта** — `i18n.js` (украинский и английский рядом, по одинаковым ключам).
- **Цвета и шрифты** — переменные в начале `public/styles.css`.
